# 백엔드·프론트 연동 기반 구축 및 후속 에이전트 확장

2026-11-13 기준 로컬 구현 현황입니다. 중간발표 MVP의 실행 기반을 공유하며, 전체 업무 기능 또는 최종 목표 에이전트 구현 완료를 의미하지 않습니다.

## 이번 공유 범위

- React 화면과 Spring 실제 API 연결: 비상·예고 목록, 상세 근거, 시계열, 화면 알림, 다음 이벤트 재생.
- v8 데이터 시간순 재생, 설비·생산 구간·LOT 검사 연결, 통계 탐지 결과와 규칙 기반 5등급 판단 반영.
- PostgreSQL 입력 스냅샷·판단 버전·재생 상태 저장 및 조사 작업 큐 구성.
- Spring 백그라운드 조사 실행, 중복 등록 방지, 재시도, 실행권 만료, 오래된 결과 반영 차단.
- 프론트·Spring·Python·PostgreSQL Docker Compose 실행 및 재시작 복구.
- 연결 검증용으로 제한적인 LangGraph + 로컬 Ollama 조사 구현 포함. 조사 결과는 점검 안내와 근거에 반영하며 등급·순위는 변경하지 않음.

## 후속 에이전트 구현 방향

에이전트가 조사할 범위, 사용할 도구, 조사 시작 조건, 결과 검증 방식과 우선순위 반영 경계를 합의한 뒤 확장합니다. 현재 연결된 최소 조사 기능을 최종 목표 에이전트와 구분합니다. 외부 LLM API 대신 로컬 LLM을 사용합니다.

## 아직 남은 서비스 기능

- 실제 점검 착수·보류·반려·결과 저장과 현장 점검 이력 조회 API.
- 자유 챗봇 API, 사용자 인증·역할별 권한.
- 실제 MES·SCADA 연동과 출처별 어댑터, 공통 정규화 데이터 구조.
- 자동 시간 재생, 탐지 호출 대기와 화면 조회의 실행 분리.
- 운영용 백업·모니터링·배포 보강. 현재는 단일 인스턴스 로컬 시연 구성.

## 검증 및 주의사항

- 이번 공유 전 프론트 프로덕션 빌드와 fixture 계약 검사 통과.
- 통계 탐지의 일반화 한계는 남아 있으며, 성능 개선 완료로 해석하지 않습니다.
- fixture의 시나리오 목표 예고 시각과 실제 탐지기의 최초 예고 시각은 다를 수 있습니다. 실제 API는 계산 결과를 사용합니다.
- 원본 데이터셋·실행 로그·DB 내용·환경 비밀값은 이번 변경에 추가하지 않습니다. 데이터셋 경로는 로컬 환경에서 지정합니다.
